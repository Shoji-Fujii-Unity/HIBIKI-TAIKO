# 響太鼓 — HIBIKI TAIKO

This project contains a browser-based Japanese drum rhythm game.

Save the main game file as index.html and open it in a modern browser.  
No server, build step, or external assets are required.

This README supports Japanese, English, and Chinese.

---

## 日本語

### 概要

- ゲーム名: 響太鼓 — HIBIKI TAIKO
- 種類: 和太鼓リズムゲーム
- 動作環境: 一般的なPCブラウザ, モバイルブラウザ
- ファイル: index.html
- オンライン接続: 通常は不要
- データ保存: ブラウザのローカルストレージ

### 遊び方

1. 提供されたゲームファイルを index.html として保存します。
2. そのファイルをブラウザで開きます。
3. PCならキーボード, スマホなら画面タッチで操作します。
4. 曲を選んで難易度を選ぶとゲームが始まります。
5. 判定ラインの円の位置でノートを叩きます。

### 操作

PC:
- ドン: F
- カタ: J
- 一時停止: Esc

スマホ:
- 画面左: ドン
- 画面右: カタ

### スマホでの画面

- 端末を横長にするのが推奨です。
- 縦画面のまま開いた場合でも, 画面が自動で横長表示になる場合があります。
- 画面が自動回転しない場合は, 端末の自動回転設定を確認してください。

### サウンド

- 画面上部のサウンドボタンで ON / OFF を切り替えられます。
- サウンドはブラウザの Web Audio API で再生されます。
- 外部の音声ファイルは使いません。

### 言語

このゲームは次の言語に対応しています。

- 日本語
- English
- 中文

画面内の言語ボタンを押すと, ゲームUIの言語を切り替えられます。

### セーブデータ

- ハイスコア, 曲のベスト記録, 言語設定, サウンド設定はブラウザのローカルストレージに保存されます。
- ローカルストレージに保存されるデータはこのゲーム用です。
- 削除する場合は, ブラウザのサイトデータや閲覧履歴データを削除してください。
- 端末やブラウザが異なる場合, 引き継ぎはできません。

### 収録曲

多数の曲が収録されています。  
曲によって BPM, 譜面の長さ, 難易度が異なります。

### 判定

- PERFECT
- GOOD
- BAD
- MISS

高評価ほどスコアと達成率が伸びます。  
連続でヒットするとコンボが上がります。

### 注意点

- 一部のブラウザでは, 最初タップやキー入力後に音が出る場合があります。
- 画面が小さい端末では操作しにくい場合があります。
- ブロック広告拡張機能などで音が出ない場合は, 一時停止して解除してください。

## English

### Overview

- Title: Hibiki Taiko — HIBIKI TAIKO
- Type: Japanese drum rhythm game
- Platforms: Modern PC browsers, mobile browsers
- Main file: index.html
- Internet connection: Usually not needed
- Data storage: Browser local storage

### How to Play

1. Save the provided game file as index.html.
2. Open the file in a modern browser.
3. Use keyboard controls on PC or touch controls on smartphone.
4. Select a song and difficulty.
5. Hit notes when they reach the target circle on the play line.

### Controls

PC:
- DON: F
- KAT: J
- Pause: Esc

Smartphone:
- Left side of the screen: DON
- Right side of the screen: KAT

### Landscape View

- Landscape mode is recommended on smartphones.
- If the device is in portrait mode, the game may automatically display in landscape.
- If it does not rotate, check your device rotation settings.

### Sound

- You can toggle sound ON or OFF from the top sound button.
- Sound is generated by the browser Web Audio API.
- No external audio files are used.

### Languages

This game supports:

- Japanese
- English
- Chinese

Use the language button in the game UI to switch the interface language.

### Save Data

- High scores, best results, language settings, and sound settings are stored in browser local storage.
- The saved data is only for this game.
- To delete data, clear site data or browsing data from your browser.
- Save data does not transfer automatically between devices or browsers.

### Songs

Many songs are included.  
Songs have different BPM values, chart lengths, and difficulty levels.

### Judgement

- PERFECT
- GOOD
- BAD
- MISS

Higher judgement increases score and accuracy.  
Consecutive hits increase combo.

### Notes

- Some browsers may start audio only after the first tap or key press.
- Small screens may be harder to play on.
- If sound does not play, try pausing the game or disabling ad blockers.

## 中文

### 概要

- 游戏名称: 響太鼓 — HIBIKI TAIKO
- 类型: 和太鼓节奏游戏
- 运行环境: 常见PC浏览器, 移动浏览器
- 主要文件: index.html
- 网络连接: 通常不需要
- 数据存储: 浏览器本地存储

### 玩法

1. 将提供的游戏文件保存为 index.html。
2. 用现代浏览器打开该文件。
3. PC使用键盘, 手机使用屏幕触控操作。
4. 选择歌曲和难度后即可开始。
5. 在判定线圆环位置击中音符。

### 操作

PC:
- DON: F
- KAT: J
- 暂停: Esc

手机:
- 屏幕左侧: DON
- 屏幕右侧: KAT

### 横屏显示

- 手机建议使用横屏。
- 若设备处于竖屏, 游戏可能会自动以横屏显示。
- 如果画面没有自动旋转, 请检查设备的自动旋转设置。

### 音效

- 可以通过顶部的音效按钮开启或关闭声音。
- 声音由浏览器 Web Audio API 生成。
- 不使用外部音频文件。

### 语言

本游戏支持以下语言。

- 日本語
- English
- 中文

点击游戏界面中的语言按钮, 可以切换界面语言。

### 存档数据

- 最高分, 最佳记录, 语言设置, 音效设置会保存在浏览器本地存储中。
- 保存的数据只用于本游戏。
- 如果要删除数据, 请在浏览器中清除站点数据或浏览数据。
- 不同设备或浏览器之间不会自动同步存档。

### 收录曲目

包含大量歌曲。  
不同歌曲有不同的 BPM, 谱面长度和难度。

### 判定

- PERFECT
- GOOD
- BAD
- MISS

判定越高, 分数和达成率越高。  
连续命中会提升连击数。

### 注意事项

- 某些浏览器可能在首次点击或按键后才开始播放声音。
- 屏幕较小的设备可能较难操作。
- 如果声音没有播放, 可尝试暂停游戏或关闭广告拦截工具。
